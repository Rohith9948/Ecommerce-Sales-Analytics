# E-Commerce Sales & Profitability Analytics

## 📊 Project Overview

An end-to-end data analytics project analyzing e-commerce sales,
customer behavior, product performance, regional trends, and profitability.

## 🎯 Objective

The objective of this project is to identify revenue drivers,
profitable products and categories, customer trends, and
potential areas for improving profitability.

## 🛠️ Tools & Technologies

- MySQL
- SQL
- Power BI
- DAX

## 📈 Power BI Dashboard

The interactive Power BI dashboard provides a single-page view of:

- Sales Performance
- Customer Analysis
- Product Performance
- Regional Analysis
- Profitability Analysis
- Discount Analysis
- Key Business Insights

### 1. Executive Overview
- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Sales Trends
- Category Performance
- Regional Performance

### 2. Product & Customer Analysis
- Top Products
- Top Customers
- Sales by Sub-Category
- Customer Segment Analysis

### 3. Profitability Analysis
- Profit by Category
- Profit by Region
- Discount vs Profit
- Top Profitable Products
- Loss-Making Products

## 💡 Business Insights

- Office Supplies generated the highest category-level profit.
- Technology was the second-highest profit contributor.
- Furniture showed comparatively lower profitability.
- Product-level profitability varied significantly.
- Several products generated negative profit and require further investigation.

## 📊 Dataset

The dataset contains 51K+ e-commerce transaction records with information about:

- Customers
- Products
- Categories
- Sales
- Quantity
- Discounts
- Profit
- Regions
- Shipping
